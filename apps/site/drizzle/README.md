# waitlist migration

`0000_waitlist_init.sql` creates the `waitlist` table only (generated by drizzle-kit from
`packages/db/src/schema/waitlist.ts`, then made idempotent with `IF NOT EXISTS`).

To merge with P0: copy the SQL into P0's migrations folder as the next numbered file and add it to
P0's drizzle journal (or run it as-is; it is safe to run twice). The drizzle-kit `meta/` snapshot is
deliberately not committed so it can't conflict with P0's journal.

Locally: `pnpm --filter site db:migrate` applies it to `DATABASE_URL`.
